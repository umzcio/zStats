# zStats identity

## Official app icon

The source of truth is `zStats.icon/`, the original Apple Icon Composer document. Its logo, texture, layer positions, gradient, translucency and shadow settings are compiled directly with Xcode's `actool`.

`scripts/build-app.sh` requires Xcode 26 or later and packages the compiler's `Assets.car` plus `zStats.icns` fallback. Both `CFBundleIconName` and `CFBundleIconFile` identify zStats. The app refreshes its running Dock icon from the compiler-generated ICNS to avoid stale icons during in-place rebuilds. This runtime refresh uses the static fallback; the layered catalog remains packaged for system icon lookup. The source document is never rewritten by the build.

`zStats Exports/` contains the six supplied PNG previews. They remain untouched. `scripts/make-icon.swift` is retained as a manual PNG-to-iconset fallback, but is not used by the normal build. Do not add padding or rasterize the Composer document before compiling it.

## Monochrome mark and earlier concept

`Sources/zStats/BrandMark.swift` supplies the compact menu-bar vector. CPU icon widgets and the empty-layout fallback use this mark with the existing widget tint or template appearance. Other metric icons and saved widget layouts are preserved.

The standalone `zstats-white.svg`, `zstats-black.svg` and `zstats-menu.svg` are vector mark exports. `zstats-app.svg` and `zstats-app.png` are the earlier charcoal app-icon concept, retained as design references; they are no longer build inputs or regenerated by the build.
